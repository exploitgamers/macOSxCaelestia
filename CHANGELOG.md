# Changelog

What changed in each release of the installer, newest first. Every release is named after the day
it was published (`vYYYY.MM.DD`) and can be downloaded from the GitHub releases page.

**How to read the automatic lines:**

- *Built for Hyprland 0.57.0-1.1, Qt 6.12.0 and Python 3.14* lists the versions the bundled parts were made for.
  Hyprland draws the windows, Qt draws the top bar and dock, Python runs the helper tools. If your system has
  different versions, the installer adapts or warns you (see Known limits in the README).
- *Package updates: a 1.0 → 1.1* means a bundled app or library moved to a newer version.
- *Updated: …* names the parts of the desktop whose settings or code changed: the dock and widgets, the top bar
  (Caelestia), the window title bars, the Hyprland settings (window behaviour and shortcuts), the app themes and icons,
  the helper commands (`rice-*`), or the wallpaper.

## v2026.11.04

- Pressing the volume or brightness keys briefly opens the volume/brightness drop-down under the top bar again
  (moving the mouse used to close it at once).
- Apps opened from the dock get the desktop session's settings again. Some apps, such as ZapZap, failed to
  start after the shells had been restarted from a terminal.
- Desktop widgets can be customised: right-click one and choose Edit. The options are clock style and city,
  first day of the week, weather location and units, which batteries or system meters to show, the Notes text
  size, the timer presets and the Photos folder.
- Apple-style icons across the dock's menus, Spotlight, the launcher, Settings and the widget gallery, and in the
  top bar: battery, Wi-Fi, volume and brightness symbols, round Control Center toggles, and notification icons.
- With Caffeinated on (the coffee cup in the battery drop-down, formerly "Block sleep and screen locking"), closing the laptop lid no longer sleeps or locks it:
  the laptop keeps running and only the screen goes dark. Opening the lid turns the screen back on.
- Caffeinated now stays on when the top bar restarts; it only turns off when you log out or restart the laptop.
- Top bar icons and text are centred again: the icons sat almost 1 px high, the pills had 1-2 px more room on
  the left than the right, the bell sat off the middle of its hover circle, and one gap between pills was wider.
- Desktop widgets are evenly padded again in every size (clock, weather, calendar, network, reminders, batteries,
  system, music, conditions, app widgets and the widget editor). Pressing a preview in the widget gallery shrinks
  it about its centre.
- The "Split stack" button and the Edit Widgets remove button no longer reach into the top bar on widgets in the
  top row.

## v2026.10.19

- First public release: one file that installs the whole macOS-style desktop (Hyprland, the Caelestia
  top bar, the dock, launcher, Spotlight, widgets and title bars with traffic lights) on a fresh
  CachyOS + KDE Plasma system in 5-10 minutes. Plasma stays as it was and remains available at the login screen.
- One-command install: paste a single `curl … && bash …` line into a terminal (see the README).
- The README now has screenshots of the desktop.
- Releases publish automatically: the installer is rebuilt and uploaded whenever the desktop or its
  packages change, so the download link always gives you the current version.
- The project is now called **macOSxCaelestia**, and so is the installer: download and run
  `macOSxCaelestia.run` (the one-command install in the README uses the new name).
- The installer keeps its notes and backups in `~/.local/state/macOSxCaelestia*` folders, matching the new name.
- Each release now comes with this changelog; its notes on GitHub show what changed.
- Fixed: on plain Arch (not CachyOS) the installer stopped silently while installing packages, so none
  of the desktop's settings were copied and Hyprland started with its default look. The cause was the
  PipeWire volume control (pwvucontrol), which only CachyOS's own repository carries; it is now bundled
  with the installer like the other AUR apps, and the build refuses any package missing from Arch's repos.
- If installing packages fails, the installer now stops with a clear message that your settings were
  not installed yet, so you can fix the problem pacman shows and simply run it again.
- If the title-bar plugin has to be rebuilt for your Hyprland and its build tools can't be installed,
  the installer now carries on without title bars instead of stopping before your settings are copied.
- Already installed on plain Arch and got Hyprland's default look? Download the new file with the same
  one-command install and run it again; it picks up where the old one stopped.
- The README has a new Troubleshooting section, notes that no AUR helper (yay, paru) is needed, and
  lists the CPU the bundled apps need (x86-64-v3: Intel Haswell / AMD Zen 1 or newer).
